# LastHouse: Pitch Deck (React + Vite + Tailwind)

## Quick start
```bash
npm install
npm run dev
```
Then open the local URL that Vite prints (usually http://localhost:5173).

## Build & deploy
```bash
npm run build
npm run preview   # to test the production build
```

Deploy the `dist/` folder to any static host or connect the repository to Vercel/Netlify.

### Notes
- Tailwind is preconfigured.
- Dependencies: framer-motion, lucide-react, recharts.
- Edit data in `src/App.jsx` (revenueGrowth, channelMix, unitEconomics, roadmap, partner/investor sections).
